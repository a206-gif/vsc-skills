## 角色包

### 顾沉(男主 · 落魄剑修,隐雷灵根)

- 服装:藏青+月白道袍,云纹内衬,深色束腰+玉牌。
- 表演提示:常态冷峻;愤怒为压抑式(咬牙、垂眸);爆发时金瞳+金蓝雷光剑气。

- 锚点:165cm,纤细;鹅蛋脸、柳叶眉、凤眼;银流苏步摇、冰晶耳坠;冰晶灵剑。

- 表演提示:清冷为主,温柔为辅;坚定时眼波下压。

### 幽冥魔尊(反派 · 千年宿敌)
- 锚点:190cm,宽肩压迫体型;竖瞳赤眼;左颊魔纹;披散长发;暗紫魔气。
- 服装:黑赤魔骨甲(肩刺、肋骨胸甲)、碎边战裙、前臂锁链;链柄魔刀。
- 表演提示:冷笑—凝视—暴怒三段式。

## 使用建议

- 以 `01–03` 作为漫剧分镜/生图的身份垫图;表情与动作从 `04` 取参考。
- 多镜头提示词中保持「不可变锚点」(脸/发型/佩件),只让情绪、伤痕、魔气浓度等「可变状态」变化。
- 需要新服装/新表情时,沿用本包锚点描述再生成,避免角色漂移。
